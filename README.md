# E-commerce Sales Analysis

Проект по анализу продаж интернет-магазина с использованием PostgreSQL и SQL. Проект демонстрирует навыки работы с реляционными базами данных, агрегации показателей, анализа прибыльности товаров и клиентского поведения.

## Цель проекта

Проанализировать продажи интернет-магазина, определить наиболее прибыльные товары, оценить динамику выручки и изучить повторные покупки клиентов.

## Инструменты

- **PostgreSQL** — хранение и обработка данных.
- **SQL** — запросы для анализа данных.
- **DBeaver** — подключение к базе данных и выполнение запросов.
- **GitHub** — хранение и документирование проекта.

## Структура базы данных

Проект использует четыре связанные таблицы:

| Таблица | Содержание |
|---|---|
| `customers` | Информация о клиентах |
| `products` | Товары, категории, цены и себестоимость |
| `orders` | Заказы, даты и статусы |
| `order_items` | Состав заказов, количество и цены товаров |

Связи между таблицами позволяют анализировать продажи на уровне заказа, товара и клиента.

## Методология расчётов

**Выручка**

Выручка рассчитывается как произведение количества проданных единиц на цену продажи с последующим суммированием по выбранному периоду или группе.

**Себестоимость проданных товаров**

Себестоимость рассчитывается как произведение количества проданных единиц на себестоимость одной единицы товара.

**Валовая прибыль**

Валовая прибыль определяется как разница между выручкой и себестоимостью проданных товаров.

**Валовая маржинальность**

Валовая маржинальность показывает долю валовой прибыли в выручке и рассчитывается в процентах.

**Средний чек**

Средний чек рассчитывается как выручка, делённая на количество доставленных заказов.

**Повторные клиенты**

Повторным считается клиент, у которого более одного доставленного заказа.

**Динамика выручки**

Для сравнения выручки с предыдущим месяцем используется оконная функция `LAG()`.

## Условия анализа и ограничения

- В аналитических запросах учитываются заказы со статусом `delivered`.
- Используются синтетические учебные данные, а не реальные данные коммерческой организации.
- Валовая прибыль не является чистой прибылью: расходы на маркетинг, доставку, зарплаты, налоги и другие операционные затраты не учитываются.
- Результаты предназначены для демонстрации навыков SQL и анализа данных.
