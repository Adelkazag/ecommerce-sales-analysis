# E-commerce Sales Analysis

Учебный проект по анализу продаж интернет-магазина на PostgreSQL и SQL.

## Бизнес-задачи
- Выручка по месяцам.
- Валовая прибыль и маржинальность.
- Сравнение товаров по выручке и прибыли.
- Анализ продаж по клиентам.
- Доля клиентов с повторными доставленными заказами.
- Динамика выручки месяц к месяцу с `LAG()`.

## Инструменты
PostgreSQL, SQL, DBeaver.

## SQL-файлы
- `sql/00_setup_schema_and_data.sql` — создание таблиц и учебных данных; запускать один раз в пустой базе.
- `sql/01_monthly_sales.sql` — выручка по месяцам.
- `sql/02_profit_analysis.sql` — валовая прибыль и маржинальность.
- `sql/03_product_analysis.sql` — анализ товаров.
- `sql/04_customer_analysis.sql` — анализ клиентов.
- `sql/05_repeat_customers.sql` — повторные клиенты.
- `sql/06_sales_dynamics.sql` — динамика выручки.

## Методология и ограничения
Учитываются заказы со статусом `delivered`. Выручка = количество × цена продажи. Валовая прибыль = количество × (цена продажи − себестоимость). Это не чистая прибыль: доставка, маркетинг, зарплаты, налоги и прочие операционные расходы не включены. Данные синтетические и предназначены для демонстрации SQL-навыков.
